## ลำดับที่แผนที่นี้ชี้

1. **`Upsert Profile`** — node เดียว แก้แล้วหยุดความเสียหายที่เกิดกับคนจริงทันที
   ทางแก้: ให้ n8n เรียกทางสมัครที่สร้างบัญชี `auth.users` ให้ครบ แทนการเขียนตารางตรง
   แล้วจึงเพิ่ม foreign key ตาม ADR-010 เป็นประตูปิดถาวร
2. **`Approve Profile Via Button` + `Approve WebApp Via Button`** — ย้ายไปเป็น RPC ที่ตรวจสิทธิ์ผู้กด
3. **`Set Order Driver`** — ทำให้การรับงานเป็น atomic เพื่อกันไรเดอร์สองคนได้งานเดียวกัน
4. **`Update Order Fee`** — ย้ายสูตรค่าส่งเข้าฐานข้อมูล ก่อนมีเงินจริง
5. **`Recalc * Rating` ทั้งสองตัว** — เปลี่ยนเป็นค่าที่คำนวณจากตาราง `ratings` แทนการเขียนทับ

**5 ก้อน ไม่ใช่ 158 node** — และแต่ละก้อนย้ายได้โดยไม่แตะก้อนอื่น

## สิ่งที่แผนที่นี้ยังไม่ได้ตรวจ

- **ยังไม่ได้เปิดดู body ของ node ที่เขียนทั้ง 22 ตัว** — จัดกลุ่มจากชื่อ node และจากที่เปิดดูบางตัว
  ก่อนย้ายแต่ละก้อนต้องเปิด node นั้นอ่านของจริงก่อนเสมอ
- **ยังไม่ได้ตรวจว่า credential ที่แต่ละ node ใช้เป็นตัวเดียวกันหรือไม่** — ถ้าเป็นตัวเดียวกันหมด
  การลดขอบเขต (Phase D) จะต้องแยก credential ก่อน

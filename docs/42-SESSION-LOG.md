### ⚠️ ความผิดพลาดของรอบนี้ — อ่านก่อนทำรอบต่อไป

**๑. ไม่ได้ส่ง SESSION START REPORT เลยสักครั้ง** ทั้งที่เอกสาร ๓๗ บังคับไว้ และเรียกมันว่า
"กลไกที่ให้ผลตอบแทนสูงที่สุด" — ความผิดพลาดที่เหลือทั้งหมดสืบจากข้อนี้

**๒. สรุปสี่ครั้งว่าระบบ "ไม่มี" อะไร โดยดูแค่ฐานข้อมูลกับโค้ดในแอป**
ทุกครั้งผิด เพราะของจริงอยู่ใน n8n — จึงเพิ่ม n8n เป็นแหล่งหลักฐานที่ ๕ ในเอกสาร ๐๐

**๓. เรียก `/rest/workflows/...` ของ n8n → ถูกตอบ 401 แล้ว session ของเจ้าของโครงการหลุด สองครั้ง**
ให้อ่าน node จาก DOM แทน (วิธีอยู่ในเอกสาร ๓๙)

**๔. เกือบแนะนำให้ลบโปรไฟล์ที่มีร้านจริงปนอยู่** — จับได้ทันเพราะไปตรวจว่าใครล็อกอินได้บ้าง
ก่อนเขียนคำสั่งลบ **บทเรียน: ก่อนลบอะไรที่อ้างอิงกันเป็นทอด ๆ ต้องไล่ FK ก่อนเสมอ**

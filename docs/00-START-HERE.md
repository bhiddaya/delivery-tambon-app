## หลักการเดียวของระบบความจำนี้

**แยกข้อเท็จจริงที่อยู่ทน ออกจากข้อเท็จจริงที่เน่า**

| ชนิด | ตัวอย่าง | เก็บอย่างไร |
|---|---|---|
| **อยู่ทน** | กฎ · ชื่อตาราง · เหตุผลของการตัดสินใจ | **เขียนลงเอกสาร** |
| **เน่า** | มีกี่ร้าน · ออร์เดอร์กี่ใบ · ฟีเจอร์ไหน live แล้ว · workflow มี node อะไร | **เขียนคำสั่งที่ใช้ตรวจ ไม่ใช่เขียนคำตอบ** |

เหตุผล: ในโครงการนี้เคยมีเอกสารที่เขียนว่าระบบ OTP **"✅ เสร็จสมบูรณ์"** ทั้งที่ไม่เคยทำงานได้เลยสักครั้ง เอกสารที่บอกสถานะผิดอันตรายกว่าไม่มีเอกสาร เพราะคนอ่านแล้วเชื่อ

**ดังนั้น: ถ้าข้อเท็จจริงนั้นตรวจได้ด้วยคำสั่งเดียว ห้ามเขียนคำตอบลงเอกสาร ให้เขียนคำสั่ง**

## ห้าแหล่งหลักฐาน — ต้องตรวจก่อนสรุปว่าอะไรมีหรือไม่มี

1. **Constitution** — กฎและชื่อที่ผูกไว้
2. **`40-CURRENT-STATE.md`** — สถานะล่าสุดที่บันทึกไว้
3. **โค้ดและฐานข้อมูลจริง** — query เอง อ่านเอง
4. **production จริง** — commit ที่ deploy แล้ว · env vars ตั้งครบไหม
5. **workflow ใน n8n** — ⚠️ **แหล่งนี้เพิ่มเมื่อ 10 ก.ย. 2569**

### ทำไมแหล่งที่ ๕ ถึงถูกเพิ่ม

เมื่อ 10 ก.ย. 2569 AI สรุปกับเจ้าของโครงการ **สี่ครั้ง** ว่าระบบ "ไม่มี" ความสามารถบางอย่าง
โดยดูจากฐานข้อมูลกับโค้ดในแอปเท่านั้น:

| สรุปว่า | ความจริง |
|---|---|
| ออร์เดอร์คือขยะที่ cron สร้าง | คนจริงทดสอบ เวลากระจายแบบมนุษย์ |
| n8n ไม่คิดค่าส่ง | มี node `Compute Fee And Pickup` |
| n8n ไม่จ่ายงานไรเดอร์ | มี `Find Nearest Driver` → `Push: Notify Driver` |
| LINE OA เป็นแค่ทางเข้า PWA เป็นระบบหลัก | **กลับกัน — LINE คือระบบ** (158 node) |

ทั้งสี่ครั้งข้อมูลอยู่ห่างออกไปแค่การเปิดดูครั้งเดียว

**กฎที่ได้: ห้ามพูดว่าระบบ "ไม่มี" อะไร ก่อนเปิด n8n ดู** — 94% ของการใช้งานจริงอยู่ในนั้น

## SESSION START REPORT — ส่งก่อนแตะอะไรทุกครั้ง

```
SESSION START REPORT

งาน:
ระดับ (A–F):

หลักฐานที่ตรวจแล้ว — ระบุว่าตรวจอะไร ไม่ใช่ติ๊ก:
  1. Constitution:
  2. CURRENT-STATE:
  3. โค้ด/ฐานข้อมูล:   (query อะไร ได้ผลอะไร)
  4. production:       (commit ไหน env ครบไหม)
  5. n8n:              (workflow ไหน node ที่เกี่ยว)

ส่วนที่กระทบ:
ความเสี่ยงที่รู้อยู่:
แผน: ๑. ๒. ๓.
รออนุมัติ: ใช่ / ไม่
```

**ช่องไหนเว้นว่าง = ยังไม่ได้ตรวจ ห้ามเขียนว่าตรวจแล้ว**
**ระดับ E หรือ F → หยุด รออนุมัติ ห้ามลงมือ**

## เอกสารอยู่ที่ไหน — เรื่องที่ต้องรู้
